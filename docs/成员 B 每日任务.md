# 成员 B 每日任务

下面这份是 **成员 B** 的每日任务安排，定位是项目的 **接口联调与演示负责人**。

现在项目里的 **Docker 和 Etcd 都部署在 A 的电脑上**，所以 B 不再负责环境搭建，
而是专注于：

**把服务端接口在 Apifox 里测通，把演示流程串起来，把录屏和答辩演示准备好。**

------

## B 的职责范围

B 主要负责这些内容：

```text
1. Apifox 接口测试
2. 发布 / 查询 / 回滚 / watch 的联调验证
3. 演示流程命令整理
4. 录屏环境准备
5. 演示脚本和操作顺序
6. 问题复现与联调反馈
7. 现场演示兜底方案
```

B 最终要交付的是：

```text
1. 所有核心接口在 Apifox 里能跑通
2. 演示流程有固定顺序
3. 出问题时能快速定位是接口、参数还是时序问题
4. 答辩时可以稳定展示完整链路
```
