# 成员 C 每日任务

下面这份是 **成员 C** 的每日任务安排，定位是项目的 **文档与测试负责人**。

现在项目里，**Docker 和 Etcd 都在 A 的电脑上统一部署**，接口联调主要通过 **Apifox** 完成。
所以 C 的重点不是搭环境，而是：

**把接口文档、测试用例、测试记录、README 和答辩材料整理成可交付版本。**

------

## C 的职责范围

C 主要负责这些内容：

```text
1. API 文档
2. 测试用例设计
3. Apifox 测试记录整理
4. README
5. 项目结构说明
6. 需求分析 / 设计说明整理
7. 测试报告
8. Demo 文案与答辩材料
```

C 最终要交付的是：

```text
1. 文档齐全
2. 接口说得清楚
3. 测试结果可复现
4. 报告能直接交
5. 老师或同学能照着文档理解项目
```
