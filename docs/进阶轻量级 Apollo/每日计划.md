# GoLiteConfig 进阶轻量级 Apollo 每日计划

## Day1：命名空间模型与核心设计定稿

目标：完成轻量级 Apollo 的核心模型设计，为后续代码改造定结构、定边界、定命名。

今日任务：

1. 确定 `app + env + namespace` 的配置维度模型。
2. 完成新版 Etcd Key 结构设计。
3. 明确 namespace 下的版本、current、meta 组织方式。
4. 补充发布、查询、版本接口的请求与响应模型。
5. 输出 Day1 设计结论文档。

今日产出：

- `任务计划书.md`
- `DAY1-核心设计确认.md`
- `DAY1-Key 设计.md`
- `DAY1-API 草案.md`

验收标准：

1. 能清晰解释 namespace 为什么要引入。
2. 新 Key 结构能支撑发布、查询、版本、回滚。
3. API 模型能覆盖当前主链路。
